# AE 资源工作台（CEP 面板）使用说明

一个装在 After Effects 里的面板：**左边浏览文件夹、看素材内容、双击导入工程**；右边标签切到**效果库**，收录 `AE学习工作台` 的 951 条 AE 插件汉化名，点一下复制名字、或直接应用到选中图层。

---

## 1. 安装（3 步）

1. 在本目录打开 PowerShell / pwsh，运行：

   ```powershell
   pwsh -File install.ps1
   ```

   脚本会：检查文件 → 校验 manifest → 复制到 `%APPDATA%\Adobe\CEP\extensions\com.ae.assetworkbench` → 确认 `PlayerDebugMode`（免签名面板必需，只写 HKCU，不需要管理员）。

2. **完全退出 After Effects**（任务管理器里没有 AfterFX.exe），再打开。

3. 菜单：**窗口 → 扩展 → AE 资源工作台**。面板出现后可以拖到任意面板组里，尺寸自适应。

卸载：

```powershell
pwsh -File uninstall.ps1              # 只删面板
pwsh -File uninstall.ps1 -RemoveData  # 连个人数据一起删
```

> 本机已确认：AE 2025 (25.6)、CEP 12、`CSXS.9/10/11/12` 的 `PlayerDebugMode` 均为 1，因此不需要额外配置。

## 2. 资源页：不退出 AE 看文件夹

| 区域 | 操作 |
|---|---|
| 左侧「源库」 | 常用文件夹列表。点 `＋` 添加文件夹；右键可「在资源管理器打开 / 复制路径 / 从源库移除」；源目录自动记忆 |
| 顶栏 | `←` `→` 后退前进，`↑` 上一级，中间是面包屑（逐级点击），右侧搜索框 + 「递归」开关 |
| 列表 | 列：名称 / 类型 / 大小 / 修改时间，点表头排序；文件夹永远在前。`▦` 切缩略图墙 |
| 双击文件夹 | 进入；**双击文件 = 导入到 AE 项目面板** |
| 右键文件 | 导入到项目面板 / 导入并加入当前合成 / 作为图片序列导入 / 在资源管理器中显示 / 复制完整路径 / 复制文件名 / 加入源库 |
| 右侧预览 | 图片（含尺寸）、视频（可直接播；ProRes 等编码自动用 ffmpeg 转 480p 代理）、音频、文本前 128KB、`.aep` 信息卡、文件夹统计 |
| 底部 | 选中计数、`导入选中`、`全部导入`（>60 个会二次确认）、视图切换 |

**键盘**：`↑`/`↓` 移动，`Enter` 导入或进入，`Backspace` 上一级，`Ctrl+A` 全选，`Esc` 取消选择，`Ctrl+F` 搜索，`F5` 刷新，`Alt+←/→` 后退前进。

**安全**：面板对素材目录**只读**——不会删除、改名、移动任何文件；生成的缩略图/代理只写在自己的数据目录。

## 3. 效果库页：插件汉化名

- 左侧 13 个分类（AE 自带 114 / CC 80 / BCC 276 / 蓝宝石 182 / 红巨星 42 / 第三方 9 / Ignite 22 / VideoCopilot 11 / RE:Vision 19 / Mocha 5 / 独立插件 65 / 组合推荐 7 / 快捷键 119），可搜索中文名、英文名、说明、用途。
- **单击一行 = 复制效果名称**（你选定的默认动作）。
- 右侧状态标注每条的实际情况：
  - `已安装`：名称已对上本机真实效果，点 **应用** 会加到当前选中图层；
  - `未安装`：本机没装这个插件，或名称没对上，点 **绑定** 手工指到一个已安装效果；
  - `快捷键` / `组合`：只是资料，不参与应用。
- 首次打开会自动扫描 `app.effects` 建立缓存，也可点 **扫描已安装** 重扫（装完新插件后用）。
- `＋ 添加效果`：手工新增一条（支持「名称1、名称2」多名称、可填 matchName、可选分类）。
- `⟳ 从学习工作台同步`：重新从 `D:\ae\bei-ae-creative-assistance\AE学习工作台\resources\app\data.js` 导入 951 条；你在那边更新了资料，点一下即可覆盖。
- `⚙ 资料库与映射`：查看统计、导出/导入 JSON（换机迁移）、清理缩略图缓存。

**名称怎么变成可执行的效果**：面板用四级匹配（精确 → 去空格/全半角/括号 → 包含 → 编辑距离 ≤2），命中结果写进 `effect-map.json`，可随时手工绑定覆盖。

## 4. 数据与缓存

- 数据目录：`%APPDATA%\AE-Asset-Workbench\`
  - `settings.json` 源库、上次路径、排序、视图、ffmpeg 路径、资料库路径
  - `library.json` 从学习工作台同步下来的资料
  - `user-effects.json` 你手动添加的效果
  - `effect-map.json` 中文名 → matchName 的绑定/映射
  - `installed-effects.json` 本机已安装效果缓存
  - `thumbs\`、`proxies\` 缩略图与代理视频缓存（可清理）
- 面板**不联网**、无遥测。唯一外部依赖是本机 ffmpeg（`C:\ffmpeg\bin\ffmpeg.exe` 或 PATH），没有它只是不生成视频缩略图。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 扩展菜单里没有「AE 资源工作台」 | 确认面板装在 `%APPDATA%\Adobe\CEP\extensions\com.ae.assetworkbench`（目录里应有 `CSXS\manifest.xml`），`PlayerDebugMode=1`，然后**完全退出** AE 重开 |
| 面板白屏 / 提示缺少 Node | manifest 里的 `--enable-nodejs` 被改掉了，重新运行 `install.ps1` |
| 顶部显示「AE 未连接」 | host.jsx 没加载：重启 AE；仍不行看 AE 的「脚本」是否被禁止（首选项 → 脚本与表达式） |
| 效果全部显示未安装 | 点「扫描已安装」；若仍全空，说明 AE 侧脚本调用失败，重启 AE |
| 视频不能预览 | 先确认 ffmpeg 路径（设置里可指定），ProRes/R3D 会转代理后再播 |
| 名字对不上某个插件 | 在效果库点该条「绑定」，从已安装列表里选；或者在「添加效果」里手填 matchName |
| 面板太窄看不到预览 | 面板宽度 <880px 时自动隐藏预览栏；拖宽即可 |
| 导入没反应 | 确认 AE 里已打开工程；首次导入会自动建工程 |

## 6. 目录结构（给维护用）

```
AE资源与效果浏览器\
├─ CSXS\manifest.xml         面板注册（AEFT 16.0+，CSXS 10.0+，启用 Node）
├─ client\                   HTML/CSS/JS（无框架、无构建、离线可用）
│  ├─ index.html
│  ├─ css\theme.css, layout.css
│  └─ js\core.js             纯逻辑：分类/排序/名称匹配/资料解析（可 node 测试）
│     js\cep.js              CEP 与 evalScript 桥接
│     js\nodeapi.js          Node 层：目录、ffmpeg、缓存、资源管理器
│     js\store.js            设置与映射持久化
│     js\vlist.js            定高虚拟列表
│     js\preview.js          预览栏
│     js\files.js            资源页
│     js\effects.js          效果库页
│     js\app.js              外壳：标签/弹窗/提示/设置
├─ host\host.jsx             AE 侧：info / listEffects / import / applyEffect
├─ data\effects-library.json 951 条资料（由 build\convert-data.js 生成）
├─ build\convert-data.js     资料库转换脚本
├─ test\core.test.js         逻辑回归测试（36 项）
├─ test\nodeapi.test.js       Node 层冒烟测试（15 项）
├─ test\dom.smoke.test.js     面板启动冒烟测试（15 项）
├─ install.ps1 / uninstall.ps1
├─ 说明.md / 自测清单.md
```

改完代码不用重新安装：直接改 `%APPDATA%\Adobe\CEP\extensions\com.ae.assetworkbench` 里的文件，然后关闭再打开面板即可（面板自动加载最新文件）。改完 `data\effects-library.json` 想重新生成：

```powershell
node build\convert-data.js
node test\core.test.js
node test\nodeapi.test.js
node test\dom.smoke.test.js
```
