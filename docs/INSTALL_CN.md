# 安装与检测

## 安装目录

将完整的 `KNOWMotionWorkbench` 文件夹复制到：

```text
C:\Users\你的用户名\AppData\Roaming\Adobe\CEP\extensions\KNOWMotionWorkbench
```

开发阶段使用未签名扩展时，需要为当前 CEP/CSXS 版本启用 `PlayerDebugMode=1`。重启 After Effects 后，从以下菜单打开：

```text
窗口 → 扩展（旧版）→ KNOW Motion Workbench
```

## AE 设置

在 After Effects 的“脚本和表达式”首选项中启用：

```text
允许脚本写入文件和访问网络
```

本面板不访问网络，但启用该选项可避免本地目录读取和扩展能力受限。

## FFmpeg（真实动态预览必需）

面板需要本机 `ffmpeg.exe` 将 AE 输出编码为浏览器可播放的 H.264 MP4。按以下任一方式配置：

- 将 FFmpeg 加入系统 `PATH`；
- 设置环境变量 `FFMPEG_PATH` 为 `ffmpeg.exe` 的完整路径；
- 使用 WinGet 安装到 `%LOCALAPPDATA%\Microsoft\WinGet\Links\ffmpeg.exe`；
- 或放在 `%ProgramFiles%\ffmpeg\bin\ffmpeg.exe`。

本机已检测到 FFmpeg 8.1.1，并包含 `libx264`。面板设置会明确显示“FFmpeg 可用/缺失”；依赖缺失时不会启动 AE 渲染。重新配置环境变量后请重启 After Effects。

## 快速实机检测

1. 新建合成和一个形状层，为位置添加两个关键帧。
2. 在时间轴中选中“位置”属性，刷新面板，应显示 `属性 1`。
3. 打开“弹性回弹”，保持默认参数并执行。
4. 确认位置属性出现表达式，播放时有回弹，并能用一次 `Ctrl+Z` 撤销。
5. 选中多个图层，测试“顺序排列”“批量重命名”和“当前时间标记”。
6. 切换到“预设”，首次打开会尝试读取本机 AE 官方与用户预设目录；也可点击“＋添加预设”选择 `.ffx` 文件。
7. 点击“＋扫描目录”，选择一个含子文件夹的效果库，确认左侧出现完整目录树，所有 `.ffx` 按文件名生成卡片。
8. 把鼠标停在一个没有视频的真实 `.ffx` 卡片上至少 650ms。确认卡片依次显示“AE 实渲中”“编码 MP4”，完成后自动播放缓存视频；移出卡片后应暂停并归零。
9. 也可在 `.ffx` 同目录放置同名图片或视频，例如 `水波纹.ffx` 与 `水波纹.mp4`；刷新后卡片会优先使用该视频而不触发实渲。卡片左下角会标注“AE 实渲”“同名媒体”等真实来源。
10. 打开设置可关闭“真实 FFX 首次悬停自动生成”；关闭后仍可在预设详情中点击“生成 AE 真实预览”。
11. 确认未绑定的图片、视频、JSX、AEP/AET 与 MOGRT 作为资源卡显示，但不会直接执行。
12. 选中一张真实预设卡，为它指定 PNG/WebP 缩略图；在 AE 中选中图层后点击“应用预设”。
13. 临时移动测试用 `.ffx`，点击“刷新目录”，确认该卡进入“失效路径”分类且不会执行。
14. 缩窄面板，确认侧栏目录树和卡片不会出现横向溢出；极窄宽度下卡片自动切为单列。

## 目录清单（可选）

在任意已扫描目录内创建 `folder.json`：

```json
{
  "name": "洛琪希魔法效果库",
  "category": "魔法特效",
  "cover": "cover.webp",
  "order": 10
}
```

`cover` 使用相对于该目录的路径；它会作为目录内没有同名预览的效果卡备用封面。

## 预设索引位置

面板把目录、收藏、最近使用和缩略图映射保存到：

```text
%APPDATA%\KNOWMotionWorkbench\presets.json
```

`.ffx` 和自定义缩略图仍保留在原位置，移动原文件后可用“刷新目录”更新失效状态。

自动实渲得到的 MP4 保存在：

```text
%APPDATA%\KNOWMotionWorkbench\preview-cache
```

FFX 文件修改时间变化后，旧 MP4 会被安全删除并在下次悬停时重建。

## 当前边界

- 未签名 CEP 扩展需要开发模式或签名后安装。
- “内容居中锚点”仅处理未分离位置维度、且位置与锚点没有关键帧的二维文字层和形状层；复杂父级、3D 或关键帧场景会安全跳过。
- 浏览器演示模式只验证界面，不等同于 AE 宿主实机测试。
- `.ffx` 是二进制预设，面板不能直接解析画面。V1.3.1 自动预览统一把预设应用到内置的 640×360、24fps、2.5 秒和栗薰子视频底片；旧版文字场景缓存会自动失效并重建。仅适用于文字、摄像机、音频、第三方插件、特定图层类型或多图层结构的预设，仍可能失败或不能完整代表最终效果，此时请提供同名视频。
- AE 的渲染队列调用是同步阻塞的；首次生成 2.5 秒预览时 AE 界面会短暂停顿，编码阶段不阻塞 AE。面板同一时间只执行一个实渲任务。
- 实渲会临时增加合成、固态层和渲染队列项，并从可用模板中锁定经验证的 AVI、QuickTime 或 MP4 单文件格式，同时强制关闭模板携带的渲染后导入/设为代理动作。原始输出位于独立暂存目录；完成或报错后整目录清理，同时恢复原队列开关。它不保存、不关闭工程，也不触碰现有合成内容，但可能令当前工程显示为“已修改”。
- `applyPreset()` 只调用一次，由 AE 将预设应用到当前合成中的所有选中图层；状态栏按选中图层数报告。
