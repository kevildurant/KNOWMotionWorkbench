# AE 资源工作台 · 自测清单

装好后按顺序点一遍，每项都能对得上就算通过。带 ⚠ 的是边界用例，建议也测。

## A. 安装与加载

- [ ] `pwsh -File install.ps1` 无报错，最后提示 4 行「接下来」
- [ ] `%APPDATA%\Adobe\CEP\extensions\com.ae.assetworkbench\CSXS\manifest.xml` 存在
- [ ] 完全退出 AE 重开后，`窗口 > 扩展` 里有「AE 资源工作台」
- [ ] 面板打开不白屏，顶栏右上角显示 `AE 25.x`（不是「AE 未连接」）
- [ ] 关掉面板再打开，布局和上次一样（源库、排序、视图被记住）

## B. 资源页

- [ ] 默认打开 `D:\ae`，能看到文件夹和文件，大小/修改时间有值
- [ ] 点 `＋` 添加 `D:\ae\bei-ae-creative-assistance`，出现在源库，重开面板仍在
- [ ] 双击文件夹进入，面包屑更新，`↑` 能回上一级（到盘符根 `D:\` 时 `↑` 置灰）
- [ ] 点表头按大小/时间排序，文件夹始终排在最前
- [ ] 输入关键词过滤当前目录；勾「递归」后再搜索，状态栏显示「已扫描 N 个条目」
- [ ] `▦` 切缩略图墙，图片显示缩略图；视频卡片几秒内出现首帧
- [ ] 单击文件右侧出现预览；图片显示尺寸；`.txt/.json` 显示文本内容
- [ ] 双击一张 png → AE 项目面板出现该素材
- [ ] 选中 >1 个文件 → 底部显示「已选择 N 项」→ `导入选中` 全部进入项目
- [ ] 右键 →「导入并加入当前合成」→ 合成里多出一层
- [ ] 右键 →「在资源管理器中显示」→ 资源管理器定位到该文件
- [ ] 右键 →「复制完整路径」→ 粘贴到记事本正确
- [ ] ⚠ 中文 + 空格路径的图片，预览正常、能导入
- [ ] ⚠ 打开 `C:\Windows` 这种大目录，列表滚动不卡；`.tif/.psd` 缩略图失败时显示图标而不是破图
- [ ] ⚠ 拔掉/不存在的网络盘源，点它会提示错误但不影响其它操作

## C. 视频与 ffmpeg

- [ ] 选中一个 mp4 → 右侧能直接播放
- [ ] ⚠ 选中 ProRes 的 mov → 提示「正在用 ffmpeg 生成 480p 代理」，随后能播放
- [ ] 设置里清空 ffmpeg 路径 → 视频缩略图不生成，但面板不报错崩溃

## D. 效果库

- [ ] 切到「效果库」，左侧 13 个分类，计数与资料一致（全部 951、AE 自带 114、BCC 276、蓝宝石 182…）
- [ ] 搜索「发光」有结果；搜索英文 `Glow` 也有结果
- [ ] **单击一行 → 提示「已复制效果名」，剪贴板里是中文名**
- [ ] 点「扫描已安装」，状态栏显示扫描到的数量，已安装的条目变绿色「已安装」
- [ ] 选中 AE 里的一个图层，点某条「应用」→ 图层上真的出现该效果
- [ ] 没有选中图层时点「应用」→ 弹出「请先在合成里选中至少一个图层」
- [ ] 未安装条目点「绑定」，搜索并选一个已安装效果 → 该条变「已安装」，重启面板后仍是已安装（映射已保存）
- [ ] `＋ 添加效果` 填「测试效果、别名B」→ 列表出现两条，重启面板仍在
- [ ] 右键自定义条目 → 删除 → 消失
- [ ] `⟳ 从学习工作台同步` → 提示「同步完成：951 条」，自定义条目和绑定都还在
- [ ] `⚙ 资料库与映射` → 导出 JSON → 文件生成；再导入回来不报错
- [ ] ⚠ 快捷键/组合推荐条目只显示「快捷键」「组合」标签，没有「应用」按钮

## E. 交互细节

- [ ] `Ctrl+F` 聚焦当前页搜索框；`F5` 刷新；`Alt+←/→` 后退前进
- [ ] 列表里按 `↑/↓` 移动选择并同步预览，`Enter` 导入
- [ ] 面板拖到很窄（<880px）预览栏自动隐藏，拖宽回来
- [ ] 面板拖到很窄（<640px）左侧源库隐藏，列表仍可用
- [ ] 右键菜单点空白处/按 Esc 会关闭

## F. 数据与安全

- [ ] `%APPDATA%\AE-Asset-Workbench\` 下有 settings.json、library.json、installed-effects.json
- [ ] 设置里「打开数据目录」能定位
- [ ] 「清理缓存」后 `thumbs\`、`proxies\` 清空，再次浏览会重新生成
- [ ] 全程没有对素材目录做任何写操作（只读）
